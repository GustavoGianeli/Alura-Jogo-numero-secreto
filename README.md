# 🎮 Jogo do Número Secreto (Versão Customizada)

Este é um projeto que desenvolvi originalmente durante as aulas da Alura, mas resolvi dar o meu toque pessoal e mudar a lógica para deixar o jogo mais customizado, dinâmico e com textos mais amigáveis.

## 🛠️ O que eu modifiquei e implementei por conta própria:
* **Sistema de Escolha de Dificuldade:** Criei uma lógica onde o jogador escolhe o nível no início. O script recalcula o limite do número secreto dinamicamente: Nível 1 vai até 10, Nível 2 vai até 100 e o Nível 3 vai até 1000.
* **Interatividade com o Usuário:** Adicionei um prompt para capturar o nome do jogador logo de cara. Esse nome é guardado e usado para interagir direto com a pessoa nos alertas e nas mensagens de vitória.
* **Diálogos Customizados:** Mudei todos os textos e conversas do jogo oficial do professor para deixar a experiência menos formal e bem mais natural.
* **Mensagem Secreta de Sorte:** Implementei uma verificação para o caso do jogador acertar de primeira, exibindo uma mensagem exclusiva e personalizada celebrando a sorte dele.

## 🚀 Tecnologias Utilizadas:
* HTML5 / CSS3 (Interface visual base)
* JavaScript (Lógica de escopo, estruturas condicionais e manipulação do DOM)
* API ResponsiveVoice (Integrada para narrar os textos alterados)

## 🎯 Como rodar:
1. Abra o arquivo `index.html` direto no seu navegador.
2. Coloque seu nome, defina o nível de dificuldade que quer encarar e mande os seus chutes!

3. Boa  sorte!!
